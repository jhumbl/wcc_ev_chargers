# Westminster EV Charge Points

Map of installed and planned electric vehicle charge points on Westminster's streets.

https://jhumbl.github.io/wcc_ev_chargers

Built with [MapLibre](https://maplibre.org/) and [CARTO](https://carto.com/basemaps) basemaps. Search and travel times by [openrouteservice](https://openrouteservice.org/) and [postcodes.io](https://postcodes.io/).
